# Limitations

- Confirmed COVID-19 cases are not equivalent to all SARS-CoV-2 infections.
- Confirmed death counts may differ from the true number of deaths caused by COVID-19.
- Testing availability, testing behavior and case definitions differ across places and time.
- Death attribution and reporting practices differ across jurisdictions.
- Historical surveillance values may be revised.
- Weekly correction values can be negative; the pipeline preserves source corrections.
- Missing source observations are left missing instead of being assumed to be zero.
- Per-million normalization does not remove differences in age structure, immunity, testing, reporting or surveillance systems.
- Summed reported counts are descriptive of the source series and should not be interpreted as perfectly comparable disease burden.
- The fixed end date is 2025-12-28; committed data are not presented as live/current 2026 surveillance.
- Four-week trend changes are descriptive reporting trends, not forecasts.
- The project does not perform causal inference or individual-level medical prediction.

This project is intended for analytics and portfolio demonstration.
